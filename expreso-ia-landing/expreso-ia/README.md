# Expreso IA — Landing

Landing page para `ia.expresoit.com`.

## Stack

- Next.js 14 (App Router)
- React 18
- Tailwind CSS 3
- TypeScript

## Antes de deployar — IMPORTANTE

Editar `app/page.tsx` línea 10 y reemplazar `WHATSAPP_NUMBER` con tu número real
en formato internacional sin "+" (ej: `5491145678901`).

## Desarrollo local

```bash
npm install
npm run dev
```

Abrir [http://localhost:3000](http://localhost:3000).

## Deploy

Subir a Vercel mediante drag & drop o conectando un repo de GitHub.
